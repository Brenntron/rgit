# rgit

rgit is a ruby implementation of git as a learning aid for how git works and how to better use ruby.

## Commands

> :note These five commands are the MVP. Merge, and maybe even rebase, will follow later. If I chose to go that far.

- [ ] init
- [ ] add
- [ ] remove
- [ ] status
- [ ] commit
